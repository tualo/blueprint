# Nutzung der Blueprint für KI-Agenten

Diese Datei ist der zentrale Einstieg für KI-Agenten, die ein neues Paket erstellen oder ein bestehendes Paket nach der beschriebenen Struktur anpassen sollen.

## Vorgehen

1. Lies zuerst [README.md](README.md)
2. Nutze [BLUEPRINT.md](BLUEPRINT.md) als Referenz für Anforderungen und Zielzustand
3. Verwende [IMPLEMENTATION_TEMPLATE.md](IMPLEMENTATION_TEMPLATE.md) als Startpunkt für die eigentliche Umsetzung
4. Orientiere dich an den Paketbeschreibungen in den Dokumenten des Zielpakets

## Wichtige Erwartung

Ein Agent soll mit dieser Blueprint ohne zusätzliche Rückfragen die grundlegende Struktur eines Tualo-Office-Pakets verstehen und sauber umsetzen können.
